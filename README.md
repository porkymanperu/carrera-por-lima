# La Carrera por Lima 2027 — prototipo

Prototipo browser/mobile hecho con Vite + TypeScript + Three.js y los GLB reales de Meshy.

## Ejecutar

```bash
npm install
npm run dev
```

Abre la URL que muestre Vite (normalmente http://localhost:5173).

## Controles

- A / ← : carril izquierdo
- D / → : carril derecho
- Space / W / ↑ : saltar
- En móvil: botones táctiles en pantalla

## Animaciones detectadas en el GLB de Meshy

BackRight_Run, Casual_Walk, Funky_Walk, Idle_11, Idle_12, Idle_3, Idle_4,
Idle_Turn_Left, Idle_Turn_Right, Jump_Over_Obstacle_1, Jump_Over_Obstacle_2,
Kick_a_Soccer_Ball, Look_Around_Dumbfounded, Run_02, Run_and_Leap, Running,
Walk_Turn_Left, Walk_Turn_Right, Walking, run_fast_3.

El prototipo elige automáticamente Idle, Running y Jump_Over_Obstacle_1.
